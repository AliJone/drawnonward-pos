# Security Policy

## Reporting a Vulnerability

Report security issues privately to drawnonward at info@drawnonward.org or +923182232414. Do not open a public issue for security problems.

Include the affected version (shown in the page footer and under Configuration > System Info), the steps to reproduce, and the potential impact. You will receive an acknowledgement as soon as possible, and any fix or mitigation will be coordinated with you before public disclosure.

## Supported Versions

Only the latest release receives security fixes.
